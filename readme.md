# 🎬 TikTok Post & Story Generator — PinoyProto 3D

A lightweight, web-based tool designed to create, preview, and download custom 9:16 vertical images tailored for TikTok and Instagram Stories. Built specifically to showcase 3D prints, custom CAD models, and customer deliverables for **PinoyProto 3D**.

---

## ✨ Features

- 📱 **Real-Time 9:16 Preview**: Fits standard mobile video and image post dimensions ($1080 \times 1920\text{px}$).
- ✏️ **Dynamic Content Updates**: Instant visual feedback as you change headlines, subtext, or Call-to-Action (CTA).
- 🖼️ **Image Uploader**: Upload rendering files or real-life photos of finished 3D prints directly into the canvas.
- 💾 **One-Click Export**: Converts your customized layout directly into a downloadable high-resolution `.png` file using `html2canvas`.
- 🎨 **PinoyProto 3D Branding**: Pre-styled with high-contrast text overlays and official brand color accents (`#FF5E00`).
